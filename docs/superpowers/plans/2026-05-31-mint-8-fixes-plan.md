## Executive summary

This audit produced 39 verified findings (15 bug/correctness/security/debt/test/doc findings plus 18 optimization recommendations, several overlapping on the same root cause). The codebase is healthy: the 9 KJV editions build byte-stable, the marathon core is untouched, and most findings are latent edge cases rather than live regressions. The most serious are two silent-data-loss/correctness classes — the `(\d{2})(\d{2})` aside-ID regex that mis-injects all 1 Enoch ch 100-108 notes (mirrored in `coverage.py`), and the `write_book` `{}`-attribution corruption that converts every web-UI-saved 8-field note into a schema-violating 9-field tuple — plus a true determinism break (wall-clock date baked into every OPF, defeating both byte-stability and the content-addressable cache) and three medium XSS/XML-injection vectors in the RSS feed and `/sources` console. Five distinct `subprocess.run` calls lack the project-mandatory `stdin=subprocess.DEVNULL` (W-W1), one of them on the primary user-facing HTTP build endpoint. No finding requires a marathon-core edit, no paid-API integration, and every proposed fix is additive or behavior-preserving for the KJV build path.

## Constraints carried

- **Marathon core is off-limits** — `scripts/build_standalone.py`, `scripts/core/manuscript_*.py`, `scripts/core/po_vision_store.py`, `content/manuscript/**`, `content/translations/sources/patrologia/**`, `GAPS/`: never edited; no finding above touches them.

The two *intended* OPF deltas (static date pin; `TODO_CERTIFIER_NAME`→publisher) are one-time, isolated, and gated by the hardened stability test thereafter.
- **Schema changes are additive** — `write_book` restores the 8-field / 9-field-with-non-empty-string invariant; `_book_index` adds a cache-key arg; the `html_chapter_count` guard and the new lint checks add validation only. Byte-identical when unset.

- **5-leg save per phase** — each shipped phase ends with the full sync: local commit (`save.ps1`, PowerShell — never the Bash tool) + `git push origin` (GitLab) + `git push github` (GitHub) + `git bundle` to E: + copy to F:, each leg verified. Run `ruff format` on regenerated files before the commit or the pre-commit `ruff format --check .` blocks it.
