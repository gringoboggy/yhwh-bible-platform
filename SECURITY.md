# Security Policy

**YHWH Ya' Way** is a free, non-commercial program maintained by a solo developer.
If you discover a security or privacy issue, please report it **privately** — do
not open a public issue.

## Reporting a vulnerability

Email **gringo.boggy@yhwhyaway.com** with:

- a description of the issue and where it occurs,
- steps to reproduce (if known), and
- the version or commit, if you have it.

I'll acknowledge your report as soon as I can and work on a fix. Thank you for
helping keep the project and its users safe.

## Scope

The program runs **locally on your own device** — no account, no server — so most
risk is limited to the local build and its output. Reports about the build
pipeline, the generated EPUBs, the published website, or any future hosted
component are all welcome.
