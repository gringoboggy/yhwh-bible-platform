```
10.5 ξ.4  XSS prevention sweep                  ~ 1 session · LOW
        Whitelist-based sanitization on note bodies; lint check
        for unescaped template strings; tests covering known
        XSS payload classes. THE highest-leverage security
        item — note bodies are publisher-authored and may
        innocently contain malicious HTML.

10.6 ξ.1  Input-validation audit                ~ 1 session · LOW
        Every API endpoint has a documented input contract;
        every mismatched input returns a 4xx with a clear
        message. scripts/core/validation.py with primitive
        validators; per-endpoint shape tests.

10.7 ξ.2  Path-traversal hardening              ~ ½ session · LOW
        scripts/core/safe_path.py; every endpoint that resolves
        a user-supplied path verifies relative_to(safe_root);
        strings rejected at the cheap layer (no `..`, hidden
        segments, absolute paths) before any resolution.

10.8 ω.8  Error-boundary audit                  ~ 1 session · LOW
        Every API endpoint catches Exception; every UI fetch()
        uses safeFetch (or has explicit catch). Lint check
        + integration tests.

10.9 ω.9  Atomic-write audit                    ~ ½ session · LOW
        Every destructive disk write goes through atomic_write
        + ensure_backup. Lint check `check_open_writes`;
        crash-during-write test.

10.10 ω.10 Retry & timeout policy              ~ 1 session · LOW
        scripts/core/http.py wrapper with timeout + exponential
        backoff retry; existing call sites migrate; tests
        cover timeout, 503-retry, 404-no-retry.
```
