> **⚠ KEY METHOD NOTE for ANY corpus regen (learned this session — supersedes the bare-base step in the recipe below + SESSION_PLAYBOOK §7):** `git checkout <base> -- epub_working/` → full regen is **LOSSY** — it drops `harvest_existing_langs`-preserved popup content the resolver can't rebuild (PROVEN: it wiped `vnote-paz-1-30`'s Douay+Vulgate) AND re-qualifies unrelated xref hrefs (~88). Inject is additive (won't prune orphaned asides), so to drop notes from the build do it **SURGICALLY**: from HEAD's `epub_working`, regex-remove the orphaned `note-<kind>` markers (`<a class="note-ref note-<kind>" …>…</a>`) + asides (`<aside class="note note-<kind>" …>…</aside>`) from the affected book's split file(s), then `inject --book <code>` to add the new notes. Verify CONTENT-level (aside-by-id diff), never raw line-diff. Only the changed book's split file(s) should differ.
