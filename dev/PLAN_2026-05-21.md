## 4.0 — Deadline sequencing strategy (RATIFIED 2026-05-23; deadline 2026-06-07)

**Run two tracks in PARALLEL, not serially.** The user's instinct (transcriptions are
the long pole) is correct, and the conclusion is to START the marathon NOW rather than
defer it — the longest, least-compressible task should consume calendar time earliest.
The two bodies of work draw on DIFFERENT resources, so they don't compete:

- **Critical path = the manuscript marathon (Track B).** Geʽez/Amharic Kings/Samuel
  dual-witness collation → the two standalone Bibles. PACED — one chapter per user
  check-in, script-based, OOM-aware (memories `feedback_marathon_pacing` +
  `feedback_concurrent_agent_cap`). It needs the USER's cadence + calendar days, and is
  the binding constraint on how much ships by 2026-06-07 (43+ Kings ch + Samuel — won't
  fully finish; every chapter is permanent partial progress). **Earliest start = most
  chapters.** Resume: 1Ki5 R2 → 1Ki6 → 1Sa2 → … (see `dev/IN_FLIGHT.md`).

- **Everything else = AUTONOMOUS, cleared in the gaps** (needs ~no user attention;
  "continue" suffices). Bounded + finishable well before the deadline, in order:
  1. Finish the **Phase-2 translation spine** — deuterocanon LXX, then Douay / JPS /
     Vulgate / Arabic (currently Genesis seeds). Same ingest pattern as WLC / LXX /
     Byzantine-NT (extractor → `versification.<x>_to_kjv` → regen → categorize-diff →
     epubcheck). **WLC + LXX-Greek Swete OT + Greek-NT Byzantine DONE 2026-05-23.**
     **Deuterocanon LXX PARTIAL (2026-05-23):** wis / sus (Theodotion `Sut`) / bel
     (Theodotion `Bet`) / bar / lje / **sir** / **tob** SHIPPED, versification
     INTERIOR-verified (Sirach = the full 30:25-36:16a transposition + merges; Tobit =
     ch6 offset + ch7 split/merge; `build_verses` concatenates LXX-split verse-halves

     `coord_in_canonical_extent` guard means a wrong identity map silently misplaces
     Greek without `ebible verify` catching it — so each below needs Greek↔KJV
     content alignment first. **Measured divergences (Swete vs KJV skeleton), ready
     for the follow-up:**
     - **Judith** — ch16 split+merge: KJV 16:1 = Greek 15:14; Greek 16:1 = KJV 16:2;
       yet Greek 16:25 = KJV 16:25 (a catch-up merge mid-song). ch1-15 clean (15:1-13
       identity; the extra Greek 15:14 is the song-intro). Align the ch16 song verse-
       by-verse.
     - **Tobit** — ✅ SHIPPED 2026-05-23. Short recension `Tob`: ch1-5+8-14 identity;
       ch6 offset −1 (G6:1 = KJV 5:22 tail, concatenated); ch7 multi-divergence
