Verify your download (SHA-256)

Each release includes a SHA256SUMS.txt. Comparing the checksum confirms the file arrived complete and unaltered — it matches what was posted here.

  • Windows: certutil -hashfile <file> SHA256
  • macOS: shasum -a 256 <file>
  • Linux: sha256sum -c SHA256SUMS.txt

About the security warnings

Builds are made by one person. The macOS build is notarized and should open cleanly; on Windows you may see SmartScreen the first time — click More info → Run anyway. The beta page explains this in full. You never need to disable antivirus or system protections, and this project will never ask you to.
