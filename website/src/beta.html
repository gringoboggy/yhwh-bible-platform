Public Beta

The first public build is here — early, free, and yours to try.

This is the very first release of YHWH Ya’ Way to the world. It is complete enough to build real editions, but it is an early build: expect a few rough edges, and please tell me what you find. It is free, it runs entirely on your own computer, and it keeps nothing — no account, no server, no tracking.

What “beta” means here — and a word on warnings. This is an early release, shared openly. Because it isn’t yet code-signed on every system, your computer may show you a caution the first time you open it. That’s normal for small free software; below is exactly why it happens and how to make sure your copy is genuine. You never have to turn off any protection to run it.

Get the beta

The current build is v1.0.0-beta.1. Choose your system:

Windows installer (.exe) macOS (.dmg) Linux (x86_64 .AppImage)

Downloads go live the moment the first build is posted. On Windows it is a normal installer — run it and follow the prompts. On macOS, open the .dmg and drag YHWH into your Applications folder. On Linux, make the AppImage executable and run it — no installation needed (the Linux build is x86_64; on ARM, run from source). Clicking a download fetches the file from the release host, so that host sees your request at that moment — your own click, and nothing more.

If your computer shows a warning

YHWH Ya’ Way is safe, but it is made by one person and not yet signed with a paid certificate on every platform. Code-signing certificates are costly, and this is a free, non-commercial project — so for now you may meet a first-run caution. Here is how to proceed honestly and safely.

Windows (SmartScreen)

  1. Run the installer. If a blue “Windows protected your PC” screen appears, it is SmartScreen being cautious about software it hasn’t seen many times yet — not a virus alert.
  2. Click More info.
  3. Click Run anyway, then follow the installer.

macOS

The macOS build is notarized by Apple, so it should open normally — just drag it to Applications and launch it. If a future build ever isn’t notarized and macOS blocks it, go to System Settings → Privacy & Security, scroll down, and click Open Anyway (that button appears only after you’ve tried to open the app once).

Never disable your antivirus or your system’s protections. You don’t need to, and this project will never ask you to. The steps above just tell your computer to trust this one program — nothing else changes.

Verify your download

Every release is published with a SHA-256 checksum for each file, in a SHA256SUMS.txt posted alongside the downloads. Comparing the checksum confirms your copy downloaded completely and wasn’t altered in transit — it matches the file posted here. (It proves integrity, not authorship; that is what code-signing adds.)

How to check

  • Windows: certutil -hashfile YHWH-Setup-1.0.0-beta.1.exe SHA256
  • macOS: shasum -a 256 YHWH-1.0.0-beta.1.dmg
  • Linux: sha256sum -c SHA256SUMS.txt

The published SHA256SUMS.txt for v1.0.0-beta.1 will appear here and on the releases page when the build is posted.

Prefer to run from source?

The code is source-available — you may read it and run it yourself. With Python 3.14+ installed, clone the repository and launch the program directly, with no installer at all. The exact clone command and run instructions live with the source.
